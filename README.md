# Zürich HB Wayfinding (mobile)

A 3D wayfinding model of Zürich HB that runs in the browser: levels, platforms, stairs, escalators and lifts,
with route search (Standard / No stairs / Step-free) between tracks, sectors, tram stops and exits.

Open the site on a phone, then *Share → Add to Home Screen*. After the first visit it also works offline.
Nothing is recorded or sent: routes are computed on the phone.

This folder is generated by `app/_tools/build_site.py` of the GEO 879 project. Do not edit it by hand.
